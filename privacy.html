Privacy Policy

Last updated: 2026-11-08

rclone-aletheia is a personal OAuth client used only by its developer, on the developer's own computer, to access the developer's own Google Drive through rclone.

Data accessed

The app requests access to Google Drive files and metadata solely to upload, list and download encrypted backup data in the developer's own Drive.

Data collection, sharing and storage

The app does not collect, transmit or share Google user data with the developer or any third party. OAuth tokens are stored only on the developer's own computer. No servers are operated for this app.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
